Overview

What it is

Available now, v1.10.0, on npm

Install with npx cocosuperintelligence. Files and state stay on your machine, with no telemetry and your own model keys.

All tagged releasesGuardrails guidePersona disclaimer

An advisory board of expert personas inside the coding tool you already use.

Coco Super Intelligence seats an advisory board of expert personas inside the coding tool you already use, returns one pick with the dissent named, then does the work through local skills, commands and agents.

Capabilities

What it can do today

Provably true of the code and releases available today.

01

16 to 32 personas on /SI-Decide

Ask one hard question with /SI-Decide and it seats 16 to 32 of 495 personas across 13 departments; add --debate for reaction rounds before the vote.

02

Cited public stances and stance check

Every persona answers from cited public stances, and a stance check flags anything that does not trace to a source.

03

229 skills, 388 commands and 34 agents

Ships 229 skills, 388 commands and 34 agents; a default Claude Code install delivers 191 of the skills.

04

One-command install across 16 tools

One command, npx cocosuperintelligence, installs into Claude Code, Cursor, Codex, VS Code and 12 other coding tools (16 adapters).

05

Phase state saved across chats

Writes phase state to disk, so a cleared chat does not erase the plan.

06

Local files, no telemetry, your own keys

Files stay on your machine, with no telemetry; your coding tool keeps its own model provider and keys.

07

Clean manifest uninstall

--uninstall removes only what the install recorded and restores your original files.

Roadmap

What’s cooking

The next milestones sourced from active work and release roadmaps.

01

Coco MCP server for any MCP-capable tool

A local stdio MCP server so any MCP-capable coding tool can call Coco's skills, commands, agents and persona board, with one-step harness setup.

02

Skills that improve themselves

An unattended loop scores each change against held-out tests and keeps only the ones that win, with an off switch.

03

Offline persona source checker

An offline persona checker that tests every persona's sources before it joins the board, so the board can grow without losing its citations.
