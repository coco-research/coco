## Compound flow — chains real subcommand invocations

Warn the user this is ~5x latency, confirm, then chain:

1. `/SI-Legal-Review "<topic>"` → capture findings.
2. `/SI-Legal-Analyse` on the surfaced findings → capture signals.
3. Inline mitigate-risk: each persona proposes mitigations for top risks.
4. `/SI-Legal-Decide` with findings + mitigations baked in → decision.
5. Finalize: a single action plan citing the chain of evidence with named owners.

Each chained step runs its own CoCo orchestration. `--deep` propagates to every step.
