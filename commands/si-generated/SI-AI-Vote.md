## Step 0 — Orchestration via CoCo (mitigation #3 wiring + #5 fast-approve)

Unless `--no-orchestrate` / `--cells` / `--personas` is supplied:

1. **Route selection through CoCo.** Invoke CoCo (the `coco` skill) with the prompt plus the recent conversation context, asking it to pick 16-32 `ai-super-intelligence` personas. CoCo reads `/Users/rijulkalra/code/coco/systems/superintelligence/ai/registry.json` and scores by domain-match (40%) + cell-coverage (30%) + productive-conflict pairing (30%). CoCo's conversation context is what makes the pick better than a cold standalone score.
   - **Fallback:** if `~/.coco/disabled` exists OR `--coco-off` is set, invoke `/SI-AI-Orchestrate "<prompt>"` (the light standalone scorer) instead.

2. **Confidence-tiered fast-approve (mitigation #5).** Do NOT block by default.
   - **HIGH confidence** (clear domain match, team spans 5-8 cells cleanly): print a 1-line team summary and AUTO-PROCEED.
     > `N picked. Heavy <cells>, light <cells>. Conflict pairs: X/Y, P/Q. Proceeding — reply 'edit' to redline.`
   - **LOW confidence** (weak domain match, lopsided cell coverage, or prompt is high-stakes/irreversible): use `AskUserQuestion` with approve / edit / re-pick / reject.
   - Hard 16-32 band: a redline outside the band asks for confirmation.

3. Capture the approved slug list. If the user rejects, STOP.

## Step 1 — Read approved persona files

## Step 2 — Confirm binary

If not binary, redirect to Decide or Tradeoff and STOP.

## Step 3 — Per-persona vote

Each persona votes YES / NO / ABSTAIN with a one-sentence rationale + `evidence_url`. ABSTAIN is rare — push back before allowing it.

## Step 4 — Output

Tally overall + by cell. Tie-breaker analysis if within 2 votes. Strongest YES arg + strongest NO arg. Clear recommendation.

## Output tiers (mitigation #2)

- **DEFAULT = SHORT.** Verdict / ranked table / synthesis + top-3 named dissents + one "what this missed" line. ~10-20 lines. Dissent is ALWAYS visible even in short mode (Barnes constraint).
- **`--deep`** expands to the full per-persona detail.

## Stance validation (mitigation #6)

After producing output, run a validation pass:

1. Every quoted stance MUST trace to that persona's `public_stances`, `v2_panel_attribution`, or `recent_signal_12mo`. Unmatched → label `[extrapolated]` inline.
2. Every cited stance shows its `evidence_url`. No URL → downgrade to `[extrapolated]`.
3. If >25% of the output's claims are `[extrapolated]`, prepend a warning: "Low grounding — many claims are inferred, not documented."
