Aloo Mannu

The local message and wake layer for coding agents on your machine.

Who it’s for

Developers running more than one coding agent session on the same machine.

Private, in the lab — no public download yet
In the labPrivate

01 Part one

What it does for you

Aloo Mannu routes asks, replies and updates between coding agent sessions on your own machine through local files and tool hooks, wakes the session that needs to answer, and keeps one clear record of open asks.

02 Part two

Who it’s for

Developers running more than one coding agent session on the same machine.

You run more than one coding agent session on the same machine and want them to pass work to each other without a cloud service, with nothing left unanswered.

03 Part three

What it does

Private beta: nothing here is a public release.

01

Send an addressed ask or update

Write a structured message from one coding agent session to another on your computer.

Private beta — no public screenshots yet Nothing is mocked up here.
02

Deliver through local hooks

Tool hooks surface pending messages in the receiving session without cloud polling.

Private beta — no public screenshots yet Nothing is mocked up here.
03

Close every open ask

Open asks stay visible locally until a matching reply closes them.

Private beta — no public screenshots yet Nothing is mocked up here.
