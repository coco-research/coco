# Music (not bundled)

Coco does not ship any music tracks. `/coco-ads` is tuned for the "Happy Beats / Business Moves" series by Sascha Ende at [ende.app](https://ende.app/en). Download the tracks you want yourself from ende.app, under the terms ende.app publishes there, and save them in this folder (`skills/coco-ads/assets/music/` in the repo, or `~/.claude/skills/coco-ads/assets/music/` in an installed skill) with these file names:

- `happy-beats-business-moves-vol-1-by-ende-dot-app.mp3` (2:44)
- `happy-beats-business-moves-vol-9-by-ende-dot-app.mp3` (1:54)
- `happy-beats-business-moves-vol-10-by-ende-dot-app.mp3` (1:00)
- `happy-beats-business-moves-vol-11-by-ende-dot-app.mp3` (1:28)
- `happy-beats-business-moves-vol-12-by-ende-dot-app.mp3` (1:58)

Any other track works too: put it here (or pass its path) and generate cues for it as `references/audio.md` describes. If no track is present, `/coco-ads` renders without music and tells you so.

Cue presets live in `cues/`:

- `<track-stem>.music-cues.json` contains full-track beat and strong-cue metadata.
- `<track-stem>.music-cues.md` contains compact planning guidance for the first 20-25 seconds.

These are Coco's own timing analysis of the tracks above (generated by `skills/coco-ads/scripts/analyze_music_cues.py`), not audio. They apply only when the matching track file is present.
