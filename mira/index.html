01 Part one

What it does for you

Mira turns your material into vertical short videos, the shape Reels and Shorts use, in English and Hindi, using a Python pipeline that runs on your own machine.

02 Part two

Who it’s for

Creators comfortable running a Python pipeline who want English and Hindi short videos made locally.

You make short-form video, you are comfortable running a Python project, and you want the work done locally. The repository is archived, so it is best treated as reference you can read and fork.
