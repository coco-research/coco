How to read a stage

Five labels, used the same way on every page.

Early preview
Public code you can run today. Not a stable release, and the version number says so.
Source available
A public repository with a licence. Read it, copy it, adapt it; there is no packaged release.
Archived
Public source kept as read-only reference. No active development and no packaged release.
Private beta
Used inside Coco Research. No public build and no repository link.
Private, in the lab
Built here, not released. A page exists so you can see what it is; there is nothing to download yet.
