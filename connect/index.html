Overview

What it is

Available now, v0.2.1 · v0.9.0-beta, Apple silicon

Runs natively on Apple silicon macOS 12 or later, reading local tool directories without sending machine inventory to a remote service.

The Mac app that plugs Coco into the AI coding tools on your machine.

Coco Connect is the Mac app that plugs Coco into the AI coding tools on your machine and runs the M0 memory daemon they share.

Capabilities

What it can do today

Provably true of the code and releases available today.

01

Finds installed coding tools

Finds the AI coding tools installed on your Mac and shows which ones are connected.

02

Connects and checks health

Turns each module on, checks its health and disconnects it again; it reports only what it has checked, never a guess.

03

Local M0 memory daemon

Runs the M0 memory daemon on your own machine only, behind a token, so tools reach your memory and nothing else does.

04

Native Apple Silicon Mac app

Native app for Apple Silicon Macs on macOS 12 or newer.
