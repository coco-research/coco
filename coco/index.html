Coco Super Intelligence

Argues a hard call out with expert personas, then hands it to skills.

Who it’s for

Developers and tech leads who use Claude Code, Cursor or Codex and want a second opinion before a hard call.

npx cocosuperintelligence
npm package

One command. Open-core, v2.4.0.

Available now · v2.4.0Open-core (Apache-2.0 core)

01 Part one

What it does for you

Coco Super Intelligence seats an advisory board of expert personas inside the coding tool you already use. You ask one hard question, the board argues it out, you get one pick with the dissent named, and your local skills, commands and agents then do the work.

02 Part two

Who it’s for

Developers and tech leads who use Claude Code, Cursor or Codex and want a second opinion before a hard call.

You already work in Claude Code, Cursor or Codex, and the calls that hurt are the ones with no obvious answer: architecture, scope, risk, go or no-go. You want the strongest objections on the table before you commit.

04 Part four

Install in one step

Run one command in a terminal. It clones the pinned v2.4.0 release tag into ./coco and wires your coding agent locally.

npx cocosuperintelligence
npm package GitHub release v2.4.0

Open-core: the core framework is Apache-2.0 and the Super Intelligence board is proprietary. Remove it any time with --uninstall, which removes only what the install recorded and restores your original files.
