Coco M0
Project-scoped · git-anchored · optional vectors
4
Vector Corpus
ChromaDBUpstashGemini
Optional add-on (Multimodal Memory skill). Embeds diagrams, audio, docs via Gemini Embedding. Semantic similarity retrieval. Not installed by default — zero-config path omits this layer entirely.
3
Phase State
Git.planning/Atomic
GSD system. Per-phase Markdown docs: CONTEXT (locked decisions), PLAN (task waves), VERIFICATION (7-gate audit results). Every phase commits atomically — fully reversible. Survives any context reset.
2
Project Brain
SQLiteproject_brain.db
Cross-session project knowledge. Entities: code classes, business decisions, domain terms, stakeholders. Populated via brain-update / brain-rescan. SQL joins only — no graph traversal. Auto-generates CLAUDE.local.md for L1.
1
Session Context
In-contextVolatile
Active IDE session window. Ephemeral — evaporates on context reset. Re-hydrated on next session from L2 via CLAUDE.local.md injection. No persistence guarantee; never write source-of-truth here.
L1 → volatileL2 → session-persistentL3 → phase-lockedL4 → corpus (optional)

Cognee 1.2.2
Agent-scoped · property graph · self-improving
4
Graph Store
Neo4jLadybug/KuzuNeptune
Typed entity-relationship graph. Nodes + edges with ontology validation (RDF/XML). Multi-hop k-hop subgraph extraction. Temporal validity intervals (Graphiti adapter). Edge feedback weights updated by memify(). NL→Cypher retriever targets this layer.
3
Vector Store
pgvectorLanceDBFastembed
Semantic embeddings for all entities, chunks, code, summaries. Truth-subspace reranking: accepted session learnings → centroid vectors → chunk alignment scores → promote/demote in results. Cosine distance search.
2
Relational Store
PostgreSQLSQLAlchemyAlembic
Document metadata, raw chunks, provenance stamps (pipeline + task + user). Source of truth for chunk lineage. In "unified mode", pgvector extension runs here too — single Postgres instance handles L2+L3 for ~10% faster search.
1
Session Cache
RedisSQL cacheEphemeral
Ephemeral conversation context. Fast lookups per turn. Session distillation pipeline (distill.py) runs at session end: interactions → lesson nodes → promoted to L4 graph. Closes the short-term→long-term memory loop.
L1 → volatileL2–3 → permanentL4 → permanent + temporal
