## Step 2 — Infer the DIALS from the wording (no flags needed)
- "make them argue / debate it / hash it out / contested" → set `--debate`.
- "highest stakes / irreversible / bet the company" → suggest `--debate=full` (confirm first — it is expensive).
- "in depth / full detail / leave nothing out" → set `--deep`.
- Explicit flags (`--debate`, `--deep`, etc.) always pass through and win over inference.

## Step 3 — Run it
Invoke `/SI-<Verb> "<prompt>" <dials>`. That verb calls `/SI-Orchestrate`, which picks the teams (local embedding routing; single-domain prompts auto-delegate to the one team) and the 16-32 expert panel. Before the panel runs, the user sees ONE line:
> `<Verb> · <teams> · <N> experts<, debating>` — reply 'edit' to change, anything else proceeds.
