Overview

What it is

Private, v0.1.0, not published

Version 0.1.0 in private lab use today. Packaged as a Python standard-library zipapp with zero third-party dependencies.

The local message and wake layer for coding agents on one Mac.

Aloo Mannu routes asks, replies and FYIs between agent sessions through files and hooks, waking the receiving chat and keeping one ledger of open asks.

Capabilities

What it can do today

Provably true of the code and releases available today.

01

Python 3.9+ standard-library zipapp

Runs on Python 3.9+ standard library only with zero external dependencies, built into a single aloomannu.pyz zipapp.

02

Four selftest adapter paths

Built-in selftest verifies four adapter delivery paths on disk: claude, pi, cursor and file.

03

Zero network, zero model calls

Routes messages locally through files and hooks, wrapping every delivered message body in an untrusted-data frame.

04

Append-only per-node ledger

Append-only JSONL ledgers track sent, delivered, acknowledged, dated, done and killed states under exclusive file locks.

Roadmap

What’s cooking

The next milestones sourced from active work and release roadmaps.

01

Guided first-run setup

Interactive setup verb that finds installed tools, previews hook diffs, saves backups and times a first message delivery.

02

Session join and leave verbs

Structured join and leave verbs for unbound agent sessions with approver checks, 24-hour rejection holds and preserved history.

03

Loopback web console

Local web console bound to 127.0.0.1 with an in-memory fragment token, read-only thread and ledger views, and single-node compose.
