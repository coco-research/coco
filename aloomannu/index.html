Overview

What it is

Private beta, not published

In private lab use today, running locally on Python's standard library with zero external dependencies and no cloud account.

The local message and wake layer for coding agents on your machine.

Aloo Mannu routes asks, replies and updates between coding agent sessions through local files and tool hooks, waking the receiving session and keeping one clear record of open asks.
